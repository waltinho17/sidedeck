# Alterações / Changelog

## 1.4.0 — 28/10/2026

**Novidades**
- Modelo **AMOLED** (preto puro, no lugar do antigo "Gráficos") e modelo **Afterburner**, com linhas de texto no estilo do OSD do MSI Afterburner (CPU, GPU, RAM, FPS, frametime, 1% low). Ele espelha as linhas marcadas no Afterburner ou usa as que você escolher, com nomes personalizados. Os valores têm largura fixa, então o texto não "pula" quando um número ganha um dígito.
- Modelo **Completo** responsivo: ao desligar um card, os outros se reorganizam e crescem para ocupar o espaço.
- **Imagens de fundo** (jpg, png, webp, gif) além de vídeos, com opção de ajuste na tela (automático, preencher, mostrar inteira, esticar). Imagens mostradas inteiras ganham um fundo desfocado em vez de barras pretas.
- Mais de 30 **paletas de cores** prontas e importação das cores do **OpenRGB**.
- Aba **Modelos** mais rápida: cada modelo tem os botões *Aplicar* e *Navegador*; novas imagens de prévia.
- A **versão** aparece no rodapé da janela e o app avisa quando existe uma versão nova no GitHub.
- Janela de configurações maior por padrão (1120×920).

**Correções**
- Modelo Vidro: o vídeo travava atrás dos cartões. O desfoque do vídeo dentro dos cartões agora é opcional (desligado por padrão); com imagem parada o desfoque é de graça.

## 1.4.0 (English)

- New **AMOLED** model (pure black, replaces "Graphs") and **Afterburner** model (MSI-style text lines that mirror your Afterburner OSD, with custom line names and fixed-width values).
- **Full** model reflows when cards are turned off.
- **Picture backgrounds** besides videos, with fit options; contained pictures get a blurred fill.
- 30+ color presets and **OpenRGB** color import.
- Faster *Models* tab (per-model *Apply* and *Browser* buttons) and new preview images.
- Version shown in the window footer, and a notice when a newer release exists on GitHub.
- Larger default settings window (1120×920).
- Glass model: video stutter behind the cards fixed — blurring the video inside the cards is now optional (off by default).
